# 平面図形 ステージ攻略

拓真のリクエスト「問題を解きながらステージを攻略していく」をもとに、
これまでのトレーニング（heimen-zukei）の中身を、横スクロールのステージの中に入れた教材です。パソコン用。

- `index.html`：ステージ攻略（入口）
- `train.html`：トレーニング（ステージの扉の中身。単独でも、まとまりごとに順番にできる）

## あそびかた

- `←` `→` 移動、`スペース` か `↑` でジャンプ、`↓` で土管に入る、`Esc` でメニュー
- **看板**：説明を読む。**問題の扉**：トレーニングの問題が開く。**紙ミッション**：ワークを解いて、お手本と見くらべる
- 仕掛け（橋・はね橋・鏡の階段）は、答えのとおりに動いて道になる
- 1回目でまちがえた問題の数だけハートがへる（5つ）。まちがえた問題は、その扉の最後にもう一度出る
- 「問」ブロックを下からたたくと、用語の問題（まちがえてもハートはへらない）
- **ポイントと機**：コイン1まいで1ポイント、問題に1回目で正解すると5ポイント、ボスに当てると10ポイント。50ポイントごとに機が1つ増える。ハートがなくなると機が1つへり、そのステージをやり直す
- **城のボス**：敵キャラが左右・上下に飛びまわり、ときどき地面におりて休む（「チャンス！」「いまだ！ 上からふめ」と出る）。休んでいるときに上からふむと攻撃の問題が出て、正解するとダメージ。3問正解でたおすと門が開く。まちがえた問題は正解するまで出る。飛んでいるときに横からぶつかるとハートがへる（休んでいるときと、おりてくるときは、ぶつかってもへらない）。足場が2つあるので、飛んでいるボスも足場からならふめる
- **地下世界（寄り道）**：1-5、2-6、3-1 にある土管の上で ↓ を押すと地下へ。出口の土管で ↓ を押すと地上にもどる
- まちがえた問題は、ステージえらび画面の記録に日付つきで残る

## ワーク版ファイルについて（おうちの人へ）

市販のワークと教科書の問題そのものは、このリポジトリには入れていません。
別にお渡しした `heimen-work.json` を、**インターネットに公開せず**パソコンの中に置き、
タイトル画面の「ワーク版ファイル（おうちの人用）」から1回読みこんでください。
そのパソコンのブラウザにだけ保存され、ステージとトレーニングにワークの問題が出るようになります。
公開版には、数を変えた同じ型の問題と、ページ番号を示した紙ミッションだけが入っています。

## 中2からの共同開発に向けて

ステージの並びは `index.html` の `WORLDS`、問題は `train.html` の `ITEMS` に文字で書いてあります。
行を足すと、新しいステージや問題を自分で作れます。

## 公開（GitHub Pages）

このフォルダの中身（index.html・train.html・icon.png・.nojekyll・README.md）をリポジトリのルートに置き、
Settings → Pages で `main` ブランチの `/ (root)` を選ぶと公開されます。

## BGM

場面ごとに曲が変わる。メロディ・ハモり・和音・ベース・アルペジオ・キック・スネア・ハイハットの8トラックを、ブラウザの中で鳴らしている（音声ファイルなし）。

| 場面 | 曲の感じ |
|---|---|
| タイトル | 明るく元気に（ハ長調） |
| ワールド1 図形の移動 | はねるようなリズム（ヘ長調） |
| ワールド2 基本の作図 | コンパスが回るような、きざむアルペジオ（ホ短調） |
| ワールド3 おうぎ形 | 円をえがくような3拍子のワルツ（ニ長調） |
| 地下世界 | 静かで少しなぞめいた感じ（イ短調、ベル） |
| ボス戦 | 速くて強い（ニ短調） |
| 問題を解いているとき | 落ち着いて考えられる静かな曲（音量も下げる） |

右上の「BGM あり／なし」で曲だけ、「音あり／なし」で全部の音を切りかえられる。

## 記録（Google スプレッドシート）

おうちの人がタイトル画面の「記録の送り先（おうちの人用）」に Apps Script のウェブアプリ URL と合言葉を入れると、次のことが起きる。設定しなければ何も送らない（URL と合言葉は、その端末のブラウザにだけ保存される）。

- トレーニング・ステージの扉・ボス・「問」ブロックで、1問答えるごとに ○ / × を送る（電波がないときは端末にためて、あとで送る）
- その端末に残っている、ほかのアプリの記録を1回だけまとめて送る（同じ GitHub Pages のアプリなら、方程式・比例のアプリの分も入る）
- スプレッドシートで「まだ直っていない」問題を読みこみ、トレーニングに「苦手（記録から）」が出る

## 保護者お試しモード

タイトル画面の「保護者お試しモード（おうちの人用）」→「お試しモードではじめる」。

- 全部のステージをえらべる（まだクリアしていないステージも）
- 答えた結果・クリア・ポイント・機は記録されず、スプレッドシートにも送らない
- 拓真くんのふだんの記録はそのまま残る
- タブを閉じるか「お試しモードを終わる」で、ふつうのモードにもどる

## ステージえらび（すごろくの道）

タイトル画面のステージえらびは、スタートからゴール（期末テスト）までの1本道。ワールド1 → 2 → 3 と、道がくねりながら進む。

- クリアしたマスはワールドの色になり、★が出る。次に進むマスは黄色く光り、たっくんのコマが立っている
- まだ通れないマスは灰色で、かぎがかかっている（保護者お試しモードでは全部通れる）
- ボスのステージ（城）は、マスの上に城がのっている
- 紫の分かれ道は地下世界。ステージの中の土管から入る。一度行くと「行った」と出る

## タイトル画面の音

- 開くと「クリックしてスタート」の画面が出る。クリックかスペースキーで、スタートの音とタイトルの曲が始まる（ブラウザは、一度クリックしないと音を出せないため）
- すごろくのマスにマウスをのせると、マスごとに音の高さが上がっていく「ピッ」という音
- 通れるマスを押すと決定の音のあと、ステージが始まる。かぎのかかったマスを押すと、ブブッという音と「まだ通れない」の表示

## 言葉の体験・やさしいハート・学校の進み具合（10/30 追加）

- **言葉の体験**：問題の前に、さわって確かめる看板を入れた。1-1「線の名前ははしで決まる（線分・半直線・直線）」「2点を通る直線は1本」「距離はいちばん短い長さ（垂直）」「言葉カード（いい例・悪い例）」、1-2「対応する点」、1-3「時計回り・反時計回り」、1-4「対称の軸と対応する点」。やってみるまで「次へ」が押せない
- **ハート**：1つの扉で減るハートは1つまで。ハートがなくなっても「続きから」を選べば、開いた扉はそのままで、最後に開けた扉の前から始まる
- **「問」ブロック**：今のステージまでに習う問題だけが出る
- **学校で習った**：すごろくのマスの左下の「予習」を押すと「学校 ✓」になる。ステージクリアの画面では、学校で習ったステージならワークの大問が、まだなら「予習。ワークは学校で習ってから」が出る。印はスプレッドシートの「端末データ」にも送る
